## 📊 Architecture Overview

```
┌─────────────────────────────────────────────────────────┐
│                    Vercel CDN                           │
│  (fkpizza.vercel.app → fkpizza.vercel.app/index.html)   │
└──────────────────┬──────────────────────────────────────┘
                   │
        ┌──────────┴──────────┐
        │                     │
   ┌────▼────────┐    ┌──────▼─────────┐
   │  Supabase   │    │  Cloudinary    │
   │ PostgreSQL  │    │   Image CDN    │
   │   + Auth    │    │                │
   └─────────────┘    └────────────────┘
```

**Data Flow:**
1. User loads `fkpizza.vercel.app`
2. Browser downloads `index.html` from Vercel
3. JavaScript fetches data from Supabase API
4. Images loaded from Cloudinary CDN
5. Form submissions go to Supabase
6. Admin operations use manage-admins function

## 🐛 Troubleshooting

### Common Issues

**Issue: "403 Forbidden" from Supabase**
- Check API key is correct
- Verify CORS enabled in Supabase
- Check RLS policies aren't blocking

**Issue: Cloudinary images not loading**
- Verify cloud name: `dajqdbpms`
- Check image URL format
- Verify CDN is active

**Issue: Admin login fails**
- Clear localStorage
- Check admin user exists in database
- Verify JWT token is valid

See `SETUP_GUIDE.md` for more troubleshooting steps.
